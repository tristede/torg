# Dossier d'archives - TORG

Ce dossier regroupe tous les éléments historiques, sauvegardes et scripts de migration qui ne sont pas nécessaires à l'exécution de l'application en production.

## Contenu :

- **`scripts_migration/`** : Scripts Python temporaires utilisés lors de la refonte graphique (nettoyage Y2K, passage en Reglass, corrections de syntaxe Tailwind et CSS).
- **`backups_public/`** : Sauvegardes locales des fichiers `index.html` et `style.css` avant la grande refonte.
- **`backup_old_versions/`** : Anciennes sauvegardes de versions antérieures.
- **`archive_historique/`** : Historique complet des versions v01 à v20 (2025) et exports JSON de la base de données.
- **`a_trier/`** : Images de brouillons, notes et ressources visuelles annexes.
